# FlowerPI Integrations

Community guides for connecting [FlowerPI](https://flower-pi.com) with your existing smart home sensors.

**No extra hardware required** — if your plant sensors are already in Home Assistant, you can push data directly to FlowerPI with a single automation.

---

## Guides

- [Home Assistant Setup Guide](./home-assistant/setup-guide.md) — Connect any HA plant sensor to FlowerPI (FYTA, Xiaomi Mi Flora, Tuya, Zigbee, and more)

---

## Compatible sensors

| Sensor | Protocol | Guide |
|---|---|---|
| FYTA Beam | HA Integration | [Home Assistant](./home-assistant/setup-guide.md) |
| Xiaomi Mi Flora | BLE / Zigbee | [Home Assistant](./home-assistant/setup-guide.md) |
| Tuya plant sensor | Wi-Fi | [Home Assistant](./home-assistant/setup-guide.md) |
| Zigbee plant sensor | Zigbee2MQTT | [Home Assistant](./home-assistant/setup-guide.md) |
